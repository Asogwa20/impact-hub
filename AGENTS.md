## Site architecture

- Keep this site framework-free: semantic HTML pages, one shared stylesheet, and vanilla JavaScript only.
- Keep institutional pages independently addressable with their own titles and descriptions.
- Use the shared color tokens and responsive patterns in `css/style.css`.
- Keep event photographs in the root `images/` folder and associate them with an event in `js/script.js`.
- Publish only confirmed IYDI details. Keep unknown event, gallery, leadership, social and contact details explicitly unpublished.
- Do not add a build step, framework, server-side code, database or package-manager requirement.
