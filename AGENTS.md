## Architecture rules
- Keep institutional sections as separate TanStack content routes with route-specific metadata so each can be shared and indexed independently.
- Maintain editable programmes and event initiatives in a shared typed content module; publish registration links only when configured with a confirmed HTTPS URL.
- Use shared header, footer and presentation sections with a single CSS token system to keep all pages visually consistent.
- Keep this content-driven site frontend-only; unpublished event, gallery, leadership and contact information must have honest empty states rather than fabricated content.
